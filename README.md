# 📄 Sobre o Projeto
Este é um mini projeto para a P2 de Linguagens de Programação, consiste em um simples sistema de cadastro e lista de filmes, programado em C para testar nossos conhecimentos.<br>
Nós escolhemos o tema de Acervo de Filmes e Séries porque gostamos muito de várias medias deste tópico e achamos que seria uma ideia mais legal e proveitosa de se fazer, principalmente por ser algo que a gente acompanha bastante e realmente gosta. <br>

# 👾 Desenvolvimento
Nós dividimos as funções com o Tiburcio ficando na programação e eu, Eduardo, na parte da documentação e auxiliando ele no que ele precisava fazer, fizemos um menuzinho simples com algumas funções de Cadastro, Exclusão, Listamento e Busca de filmes. <br>
Separamos os arquivos em <b>Main.c</b> onde fica o menu em si, <b>Filmes.c</b> onde fica as funções e sistemas mais complexos, <b>Filmes.h</b> para o struct e um arquivo de texto que as vezes se duplica, o <b>filmes.txt</b> e o <b>filmes_temp.txt</b>, que também armazenam os dados, em um formato <b>dado1;dado2;dado3;dado4</b> e etc., pulando linha para cada registro de filme. <br>
Definitivamente foi um sistema legal de programar, porém tivemos alguns contra tempos enquanto estávamos fazendo.

# 💻Como Executar
Usamos o GCC como compilador. <br>
Para executar é bem simples, você compila pode os dois arquivos principais novamente com o comando:<br>
```gcc Main.c Filmes.c -o Filmes.exe``` <br>
E depois para executar você utiliza (ou só usar este logo de inicio, o programa já está compilado.):<br>
```.\Filmes.exe ``` <br> <br>
